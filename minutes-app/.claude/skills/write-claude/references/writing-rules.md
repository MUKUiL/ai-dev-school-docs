# CLAUDE.md 記述のルール

- **「〜しない」には、代わりに何をするかまで書く**（例：テストが落ちたら、まず実装を疑う）。禁止だけだと代わりの行動が決まらない。
- **合否の基準を書き写さない。** 基準の置き場所は docs/spec.md の1か所。CLAUDE.md からは「spec.md を参照する」と指す。
- **判定器はラッパー表記で書く**（例：`./scripts/verify`）。ホストで素の `npm run …` を実行させない。
- **確認を挟む操作は、不可逆かどうかで選ぶ。** すべてに確認を挟むと読まずに承認するようになる。
- **停止条件は数値で書く**（回数・ファイル数）。「様子を見て」は止まれない条件。
- リポジトリの説明（ディレクトリ一覧など）は書かない。ルールだけを置く。
