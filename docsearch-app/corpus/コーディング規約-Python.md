# コーディング規約（Python）

> 株式会社テックバディ 情報システム部
> ※ 本書は架空の会社の架空の文書です。実在の企業・団体とは関係ありません。

## 基本

- PEP 8 に従う。整形は formatter に任せ、手で揃えない。
- 型ヒントを書く。公開する関数の引数と戻り値には必須とする。
- 可変オブジェクトを引数の既定値にしない。

## 命名

| 対象 | 規則 |
| --- | --- |
| 変数・関数 | スネークケース |
| クラス | パスカルケース |
| 定数 | 大文字スネークケース |
| 非公開 | 先頭にアンダースコア1つ |

## 例外

- 素の `except:` を書かない。捕まえる例外を明示する。
- 業務のルールに関する失敗は、独自の例外クラスを定義して表す。

## ログ

- `print` をアプリケーションコードに残さない。`logging` を使う。
- ログは構造化して出す。リクエストを識別できる値を必ず含める。
- 秘密情報と個人情報を出力しない。

## 依存

- 仮想環境を使い、グローバル環境に入れない。
- ロックファイルをコミットする。
