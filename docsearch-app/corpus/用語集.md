# 用語集

> 株式会社テックバディ
> ※ 本書は架空の会社の架空の文書です。実在の企業・団体とは関係ありません。

| 用語 | 意味 |
| --- | --- |
| 案件コード | 案件を識別する記号。顧客名の代わりに用いる |
| 常駐 | 顧客の事業所に出向いて作業する勤務形態 |
| 受け入れ基準 | 成果物が合格かどうかを判定する条件 |
| 検収 | 顧客が納品物を確認し、合格と認めること |
| 手戻り | 前の工程に戻ってやり直すこと |
| ADR | 設計上の判断とその理由を残した記録 |
| 稟議 | 社内で決裁を得るための手続き |
| 情シス | 情報システム部の略称 |
| 貸与物 | 会社が業務のために貸し出す物品 |
| 引き継ぎ書 | 不在時に業務を代わる者へ渡す資料 |
