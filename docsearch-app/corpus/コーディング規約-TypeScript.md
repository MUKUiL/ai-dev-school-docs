# コーディング規約（TypeScript）

> 株式会社テックバディ 情報システム部
> ※ 本書は架空の会社の架空の文書です。実在の企業・団体とは関係ありません。

## 基本

- `any` を使わない。型が決まらない箇所は `unknown` で受け、絞り込んでから使う。
- 公開する関数には戻り値の型を明示する。
- `null` と `undefined` を混在させない。値が無いことは `null` で表す。

## 命名

| 対象 | 規則 | 例 |
| --- | --- | --- |
| 変数・関数 | キャメルケース | `fetchDocuments` |
| 型・クラス | パスカルケース | `AskResult` |
| 定数 | 大文字スネークケース | `MAX_QUESTION_LENGTH` |
| ファイル | ケバブケース | `ask-handler.ts` |

## 関数

- 1つの関数は1つのことをする。50行を超えたら分割を検討する。
- 引数が4つを超えたらオブジェクトにまとめる。
- 早期 return を使い、ネストを深くしない。

## エラー

- 例外を握りつぶさない。捕まえたら、分類して記録するか、上位へ投げ直す。
- エラーメッセージに接続文字列、キー、個人情報を含めない。

## import

- 相対パスは同一ディレクトリまで。それ以上はエイリアスを使う。
- 未使用の import を残さない。
