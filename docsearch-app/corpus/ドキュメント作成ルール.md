# ドキュメント作成ルール

> 株式会社テックバディ
> ※ 本書は架空の会社の架空の文書です。実在の企業・団体とは関係ありません。

## 1. 置き場所

| 種類 | 置き場所 |
| --- | --- |
| 案件の文書 | 案件のリポジトリの `docs/` |
| 全社の規程 | 共有フォルダの「規程」 |
| 手続きの案内 | 共有フォルダの「手続き」 |

複数の場所に同じ内容を置かない。参照で1か所に寄せる。

## 2. 書き方

- 結論を先に書く。
- 1文を短くする。読点で3つ以上つなげない。
- 数値には単位と基準を添える。「速い」ではなく「中央値で20秒以内」と書く。
- 判断が必要な箇所には、誰が判断するかを書く。

## 3. 更新

- 更新したら、更新した内容が分かる形で残す。
- 古くなった文書は削除するか、冒頭に「参照しないこと」と明記する。
- 現役で参照されない文書を共有フォルダに残さない。

## 4. 用語

社内で意味が分かれる言葉は用語集に載せる。文書ごとに定義し直さない。
