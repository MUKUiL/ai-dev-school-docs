# 対象文書（配布物）

> **`3-3-8` の実装で取り込む文書です。**架空の会社「株式会社テックバディ」の社内文書という設定で、運営が用意しました。
>
> ⚠️ **すべて架空の内容です**（Constitution 第12条）。実在の企業・団体とは関係ありません。**個人情報・給与・人事評価は含みません**（要件定義書 3-2）。

## 内訳（35ファイル）

| 形式 | 件数 | 内容 |
| --- | --- | --- |
| Markdown（`.md`） | 10 | 開発ガイドライン・コーディング規約・レビュー基準など |
| プレーンテキスト（`.txt`） | 20 | 就業規則・経費精算ルール・各種手続きなど |
| PDF（`.pdf`） | 5 | 押印済みの規程類。**テキストが埋め込まれています**（スキャン画像ではありません） |

> 📌 **形式がそろっていないのは意図的です。**現場でもそろっていません（`3-3-8` 2-1）。

## 質問セットとの対応

[`../docs/notes/eval-set.md`](../docs/notes/eval-set.md) の20問は、この文書群に対して作ってあります。

### 答えが書かれている文書（Q1〜Q15）

| # | 質問 | 答えがある文書 |
| --- | --- | --- |
| 1・3・7・10 | 経費関係 | `経費精算ルール.txt` |
| 2・6・8・9 | 勤務・休暇 | `就業規則.txt` |
| 4・5・11 | 開発の決まり | `開発ガイドライン.md` |
| **12** | 退職時の返却物 | **`就業規則.txt` ＋ `情報セキュリティ規程.txt`**（複数文書） |
| **13** | ライブラリ追加の手順 | **`開発ガイドライン.md` ＋ `情報セキュリティ規程.txt`**（複数文書） |
| **14** | 長期休暇の手続き | **`就業規則.txt` の複数の条項**（第11条・第12条） |
| **15** | 押印が必要な書類 | **`各種手続き一覧.pdf`**（PDF から） |

> 📌 **12〜14 は分割の設計を判断する材料です。**断片の大きさによって、引けたり引けなくなったりします。
> **15 は取り込みの形式対応が効いているかを見ます。**

### 答えが書かれていない質問（Q16〜Q20）

**この5問の答えは、どの文書にも書かれていません。**意図的です。

| # | 質問 | 文書側の状態 |
| --- | --- | --- |
| 16 | 今年の経費申請は何件ありましたか | **件数はどこにも書かれていない** |
| 17 | 就業規則はいつ改定されましたか | 附則に「第2次改定」「第3次改定」とあるが、**日付が無い**ので時点を比較できない |
| 18 | 有給の申請が「不要」なのはどんなときですか | **「不要」という記述が無い** |
| 19 | 社員は何人いますか | **人数の記載が無い** |
| 20 | 来年の賞与はいくらですか | **賞与に関する記述が無い** |

> ⚠️ **文書を足すときは、この5問が答えられるようにならないか確認してください。**
> 答えられるようになると、`spec.md` の F-3 の判定が成立しなくなります。

## 使い方

**`3-3-8` の 2-2（チャンク分割の比較）では、5ファイルだけに絞ってください。**全35件を3通り試すと、取り込みが3回走ります。

比較に使うのは次の5ファイルを推奨します。

```
就業規則.txt
経費精算ルール.txt
情報セキュリティ規程.txt
開発ガイドライン.md
各種手続き一覧.pdf
```

**全件の取り込みは、分割の設定を決めたあと1回だけ**行ってください。

## PDF について

5件の PDF はテキストが埋め込まれています。ただし**抽出結果は必ず目で確認してください**（`3-3-8` 2-1）。改行の位置、表の列、ヘッダーとフッターの混入は、抽出の方法によって変わります。
