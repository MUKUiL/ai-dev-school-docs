# 外部サービスへの送信内容の一覧

> **クライアントの条件2への提出物**（[../hearing.md](../hearing.md) Q9）。
> 「どの外部サービスに何を送るかを一覧にして提出する」に対応する。
>
> **この文書は根拠の置き場です。**判定に使う基準は [../spec.md](../spec.md) にある。

| 項目 | 内容 |
| --- | --- |
| 最終確認日 | 2026-08-09 |
| 更新の条件 | **送信先または送信内容が変わったら、その時点で改版して再提出する** |

---

## 1. 送信先の一覧

| # | サービス | 用途 | 送るもの | 送らないもの |
| --- | --- | --- | --- | --- |
| 1 | **OpenAI**（埋め込み API） | 文書と質問のベクトル化 | ① 対象文書を分割した断片のテキスト（取り込み時・1回だけ）<br>② 利用者の質問文（質問のたび） | ファイル名以外のメタ情報／利用者の識別情報 |
| 2 | **Anthropic**（Claude API） | 回答の生成 | ① 利用者の質問文<br>② 検索で選ばれた文書の断片（最大3件） | 対象文書の全文／選ばれなかった断片 |
| 3 | **Supabase**（PostgreSQL） | ベクトルと本文の保存 | 対象文書を分割した断片のテキストとベクトル | 利用者の質問文（**保存しない**） |
| 4 | **Vercel** | アプリの実行 | 構造化ログ（[../spec.md](../spec.md) F-6 の項目のみ） | 質問文／回答本文／根拠の抜粋 |

---

## 2. 送信されるデータの範囲

**対象文書は [../requirements.md](../requirements.md) 4-3 の約35ファイルに限る。**

| 送らないと明示するもの | 根拠 |
| --- | --- |
| 給与・人事評価・個人情報を含む文書 | クライアントの条件1 |
| 過去案件の資料（約160ファイル） | 対象外（[../requirements.md](../requirements.md) 3-3） |
| 利用者が誰かという情報 | 本アプリは利用者を識別しない |

---

## 3. 各サービスのデータの扱い

> ⚠️ **各社の方針は変わります。**
> ここに書き写した内容を根拠にせず、**提出の直前に必ず各社の公式ページで確認し、最終確認日を更新してください。**（Constitution 第13条9）

| サービス | 確認すること | 確認先 |
| --- | --- | --- |
| OpenAI | API 経由の入力を学習に使わない方針か／保持期間 | 公式の利用規約・データ利用ポリシー |
| Anthropic | 同上 | 公式の利用規約・プライバシーポリシー |
| Supabase | データの保存地域／暗号化 | 公式ドキュメント |
| Vercel | ログの保持期間／保存地域 | 公式ドキュメント |

**確認した内容と確認日を、この表の下に追記して提出する。**

---

## 4. 送信を止める手段

| 状況 | 手段 |
| --- | --- |
| 送信をすべて止めたい | Vercel のデプロイを削除する。または環境変数を外す |
| 特定の文書を対象から外したい | 該当文書を削除して**取り込み直す**（[../spec.md](../spec.md) F-4） |
| 費用の上限に達した | 各サービスの上限設定により自動で停止する。アプリは `quota_exceeded` として扱う |

> 📌 **「取り込み直す」で消えることを、取り込みの設計で保証する必要があります。**
> 削除した文書の断片がデータベースに残ると、**対象外にしたはずの文書が根拠として出てきます。**
