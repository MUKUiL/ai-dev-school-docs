# ToDo アプリ 作成プロンプト

> **この文書の役割**：`1-1-1`（10分で ToDo アプリを作る）と `1-2-6`（フレームワーク版 ToDo アプリ）で、受講生が Claude Code に投げるプロンプト。
> **失敗パターンを事前に潰した固定プロンプト**です（`M1-1` 制作メモ）。受講生が「10分で動くものができる」体験を確実にするために、運営側で検証済みのものを配ります。
>
> - 作成日：2026-08-07 ／ **最終確認日：2026-08-07**（Next.js 16.3.0 で検証）
> - 対応する要件：[requirements.md](./requirements.md)

## 0. プロンプトの4点（`1-1-1` 2-2 で教える型）

このあとのプロンプトは、すべて次の4点でできています。**丸暗記ではなく、この型を持ち帰ってください。**

| # | 要素 | 何を書くか | 書かないとどうなるか |
| --- | --- | --- | --- |
| ① | **目的** | 何を作るのか。1行で | 用途を推測され、想定と違うものが出る |
| ② | **画面** | 何がどこに表示され、何が押せるのか | 画面構成を勝手に決められる |
| ③ | **データ** | 何を、どんな形で、どこに保存するのか | 保存先を勝手に選ばれる（DB を足されることもある） |
| ④ | **制約** | 使ってよい技術・使ってはいけない技術・やらないこと | ライブラリを大量に足され、読めない量になる |

**④の「やらないこと」がいちばん効きます。** 書かないと、AI は「あったほうがいいだろう」と機能を足します。

## 1. 静的版（`1-1-1` で使う）

作業ディレクトリを1つ作り、その中で Claude Code を起動してから、次をそのまま貼り付けてください。

````text
ブラウザだけで動く、1人用の ToDo リストを作ってください。

## 画面
1画面だけです。上から順に置いてください。
- 見出し「ToDo リスト」
- 入力欄と「追加」ボタン
- 「未完了 N 件 / 全 M 件」のカウンタ
- ToDo の一覧。各行はチェックボックス・本文・「削除」ボタン

## 動き
- 入力して「追加」を押すと、一覧の末尾に増える。空文字と空白だけのときは追加しない
- チェックボックスで完了・未完了が切り替わる。完了した行は打ち消し線にする
- 「削除」を押すとその行だけ消える
- 追加・完了・削除のたびにカウンタを更新する
- ブラウザを再読み込みしても内容が残る

## データ
- ToDo 1件は id（文字列）・text（文字列）・done（真偽値）の3つ
- 配列を JSON にして localStorage に1つのキーで保存する

## 制約
- ファイルは index.html・style.css・app.js の3つだけ
- 外部ライブラリ・フレームワーク・CDN は使わない。素の HTML・CSS・JavaScript で書く
- ビルドは不要。index.html をブラウザで開けば動く状態にする
- 見た目の装飾は最小限でよい

## やらないこと
- ログイン・ユーザー登録
- サーバーやデータベースへの保存
- 期限・優先度・カテゴリ・並び替え・検索
- 通知
````

### 期待される結果

3つのファイルが作られ、`index.html` をブラウザで開くと ToDo の追加・完了・削除ができます。

> **10分で終わらなかったら**：それは失敗ではありません。`1-1-1` の 2-6「動かないときの初手」に、詰まりやすい4点（起動コマンド・ポート・パス・保存漏れ）の対処があります。

## 3. Next.js 版（`1-2-6` で使う）

**静的版とは別のディレクトリ**を作って、そこで Claude Code を起動してください。同じディレクトリで作ると、静的版のファイルが混ざります。

````text
Next.js で、1人用の ToDo リストを作ってください。機能は静的版とまったく同じです。

## セットアップ
- create-next-app は使わず、package.json を手で書いて npm install してください
- Next.js 16 / React 19 / TypeScript / App Router を使います
- **npm install に -g（グローバル）は絶対に付けないでください**
- Tailwind CSS・UI ライブラリ・状態管理ライブラリは入れないでください

## 画面
1画面だけです。上から順に置いてください。
- 見出し「ToDo リスト」
- 入力欄と「追加」ボタン
- 「未完了 N 件 / 全 M 件」のカウンタ
- ToDo の一覧。各行はチェックボックス・本文・「削除」ボタン

## 動き
- 入力して「追加」を押すと、一覧の末尾に増える。空文字と空白だけのときは追加しない
- チェックボックスで完了・未完了が切り替わる。完了した行は打ち消し線にする
- 「削除」を押すとその行だけ消える
- 追加・完了・削除のたびにカウンタを更新する
- ブラウザを再読み込みしても内容が残る

## データ
- ToDo 1件は id（文字列）・text（文字列）・done（真偽値）の3つ
- 配列を JSON にして localStorage に1つのキーで保存する
- localStorage はブラウザの機能なので、サーバー側では読めません。読み書きするコンポーネントは 'use client' にしてください

## 構成
- app/layout.tsx（ルートレイアウト。html と body タグを含む）
- app/page.tsx
- 一覧・入力欄・1行 をそれぞれ別のコンポーネントに分ける
- ToDo の型と localStorage の読み書きは、コンポーネントとは別のファイルに置く

## やらないこと
- ログイン・ユーザー登録
- サーバーやデータベースへの保存
- 期限・優先度・カテゴリ・並び替え・検索
- 通知
````

### 期待される結果

`npm run dev` でローカルサーバーが起動し、`http://localhost:3000` で静的版と同じ動きになります。

> **なぜ「create-next-app は使わず」と指定するのか**：`create-next-app` は Tailwind CSS・ESLint などを一式入れます。**`1-2-6` の目的は「どのファイルが何を担うか説明できる」ことなので、説明できないファイルを最初から置かない**ためです。実務では `create-next-app` を使って構いません。

## 4. うまくいかないときに追加で投げるプロンプト

| 症状 | 投げる指示 |
| --- | --- |
| 指示していない機能が付いている | `やらないことに挙げた機能が入っています。〔機能名〕を削除して、指定した機能だけにしてください。` |
| ファイルが指定より多い | `ファイル構成を指定どおりにしてください。いま余分なファイルがあれば、何のために作ったかを説明してから消してください。` |
| 外部ライブラリが入っている | `package.json に指定していない依存が入っています。何を追加したか、なぜ必要かを説明してください。不要なら外してください。` |
| 動かない | `〔実際に出たエラーメッセージをそのまま貼る〕。原因の仮説を3つ挙げて、確かめる順番を教えてください。` |

**最後の1つが特に大事です。** 「直して」だけ投げると、原因を確かめずに書き換えられます。**エラーの全文を貼り、仮説を立てさせてから直させる**のが、この先ずっと使う型です（`1-2-7` UI のデバッグで詳しく扱います）。
